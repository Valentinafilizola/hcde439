Schematic:

This schematic uses an N-MOSFET to control a DC motor (high-load) using PWM from the Arduino (logic).
The motor is powered by an external 12V supply, while the Arduino is powered by USB, and both share ground.
A 270Ω resistor is used between D9 and the MOSFET gate to limit gate current: 5V/270Ω ≈ 0.0185A (18.5mA).
A 10kΩ pulldown resistor keeps the gate OFF during reset: 5V/10kΩ = 0.0005A (0.5mA).
A flyback diode is placed across the motor to protect the MOSFET from voltage spikes.
C1 (100µF) and C2 (0.1µF) go across +12V and GND to reduce voltage dips and noise from the motor.
The DHT sensor uses a library and sends DATA to D2 (with a 10k pull-up to 5V if needed).


Circuit:

I built my circuit like this so the Arduino controls the MOSFET gate on D9, and the motor stays on external 12V.
The grounds are tied together so the MOSFET gate voltage is referenced correctly.


Ohm's Law Calculations


Gate resistor: R = V/I = 5V/0.02A = 250Ω, so I chose 270Ω to stay under 20mA peak.
Gate pulldown: R = V/I = 5V/0.0005A = 10kΩ, so I chose 10kΩ to keep the MOSFET off at boot.


Firmware:


// Include the DHT library so the sensor input uses a library.
#include <DHT.h>

// Define the Arduino pin used for DHT sensor data.
#define DHTPIN 2

// Define the DHT sensor type (change to DHT11 if that is your sensor).
#define DHTTYPE DHT22

// Create the DHT object using the chosen pin and sensor type.
DHT dht(DHTPIN, DHTTYPE);

// Store the PWM pin used to drive the MOSFET gate with analogWrite().
const int PWM_PIN = 9;

// Store the most recent humidity reading (percent).
float humidity = 0.0;

// Store the most recent temperature reading (Celsius).
float temperatureC = 0.0;

// Store the PWM value (0–255) that controls motor power.
int pwmValue = 0;

// Run setup once to initialize Serial, sensor library, and output states.
void setup() {
  // Start Serial so sensor values and PWM values can be documented.
  Serial.begin(9600);

  // Initialize the DHT sensor library so readings work.
  dht.begin();

  // Set PWM pin mode to OUTPUT so the pin actively drives HIGH/LOW.
  pinMode(PWM_PIN, OUTPUT);

  // Set PWM to 0 so the MOSFET starts OFF during boot (safe default).
  analogWrite(PWM_PIN, 0);

  // Print a startup message for debugging/documentation.
  Serial.println("Boot: DHT + MOSFET PWM motor control");
}

// Loop forever to read sensor values and control motor speed.
void loop() {
  // Read humidity from the DHT sensor (returns NaN if it fails).
  humidity = dht.readHumidity();

  // Read temperature in Celsius from the DHT sensor (returns NaN if it fails).
  temperatureC = dht.readTemperature();

  // Check for failed sensor reads to prevent invalid control.
  if (isnan(humidity) || isnan(temperatureC)) {
    // Print an error message so the failure is visible.
    Serial.println("DHT read failed -> PWM=0 (motor off)");

    // Turn motor off by setting PWM to 0 (MOSFET gate low duty).
    analogWrite(PWM_PIN, 0);

    // Delay so the loop does not spam reads and prints.
    delay(500);

    // Return early so no invalid PWM mapping happens.
    return;
  }

  // Convert humidity (0–100%) into PWM duty cycle (0–255).
  pwmValue = map((int)humidity, 0, 100, 0, 255);

  // Constrain PWM to valid range in case of small sensor edge cases.
  pwmValue = constrain(pwmValue, 0, 255);

  // Output PWM on D9 to control MOSFET gate and motor power from external 12V.
  analogWrite(PWM_PIN, pwmValue);

  // Print humidity label for documentation.
  Serial.print("Humidity(%): ");

  // Print the humidity value for documentation.
  Serial.print(humidity);

  // Print temperature label for documentation.
  Serial.print("  Temp(C): ");

  // Print the temperature value for documentation.
  Serial.print(temperatureC);

  // Print PWM label for documentation.
  Serial.print("  PWM(0-255): ");

  // Print the computed PWM value for documentation.
  Serial.println(pwmValue);

  // Delay to keep the reading rate stable and readable.
  delay(250);
}

Circuit's Operation


This circuit uses a DHT humidity sensor (library input) and a DC motor (high-load output).
The Arduino reads humidity, maps it to a PWM value, and uses analogWrite() on D9 to drive the MOSFET gate.
The MOSFET switches the motor using the external 12V supply, while the Arduino stays on 5V USB logic power.
The flyback diode protects the MOSFET from motor voltage spikes, and the capacitors reduce supply noise.
