TerraSync Functionality

TerraSync is a lamp that has 3 entry points. One is on the side for a photoreistor that detects that brightness of the room. The second is a button on the top of the base of the lamp where a user can toggle through the different virtual states displayed on Unity. The third is an opening on the side for the USB cord.

When the photoreistor detects its in a bright room, the LEDs are dim, and the Unity scene dispalys a daytime-background. Likewise, when it it is in a dark room, the LED's glow brightly, and the virtual scene displays a dark night-time background.

The button states are for studying. When a user wants to begin a focus session, they hold the button to turn focus mode on. This in turn changes the focus state button from start -> ON, and the virtual scene displays the growth of plants and bushes. When a user wants to finish their study session, they press the button twice to turn off focus mode. After being pressed once the button state goes from ON -> Disable Focus Mode? After being pressed twice the virtual message displays -> Focus mode OFF. Which then displays the shirinkage of the plants.

Circuit:

I utilized a lot of alligator clips so that my button and photoreistor could sit comfortably outside of my breadboard
and so that they'd be visible and accessible to the lamp exterior.
Additionally, I chose to use blue, white, and yellow LED's to display visible "evening" light under my dome.


Ohm's Law Calculations

I chose to use a 220 OHM resistor for each LED because after calculating Ohm's law for each LED, 220 was the safest and most reasonable option.
Likeiwse, I calculated an example middle number for R2 for the photoreistor to show how much R2 would be if the photoresisotr was detecting "medium" brightness.

// Pin definitions
const int lightSensorPin = A0;   // photoresistor
const int buttonPin = 2;         // button

// LED pins
const int led1 = 9;   // white LED
const int led2 = 10;  // yellow LED
const int led3 = 11;  // blue LED

void setup() {

  // needed to match the speed at which serial would go to unity code
  Serial.begin(9600);

  // initializes button as an input
  pinMode(buttonPin, INPUT_PULLUP);

  // initializes LED's as outputs
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
}

void loop() {

  // Read the photoresistor
  int lightValue = analogRead(lightSensorPin); // 0–1023

  // Read the button
  int buttonState = digitalRead(buttonPin);

  // sets button as pressed as 0
  int buttonPressed = 0;

  //checks if button is pressed
  if (buttonState == LOW) {
    // button is pressed (serial comm sends this to unity as 1)
    buttonPressed = 1;
  }

  // Constrain range so LEDs dim earlier (but stay bright in darkness)
  int constrainedLight = constrain(lightValue, 0, 600);

  // Dark -> bright LEDs
  int brightness = map(constrainedLight, 0, 600, 255, 0);

  // Set LED brightness
  analogWrite(led1, brightness);
  analogWrite(led2, brightness);
  analogWrite(led3, brightness);

  // Send sensor data to Unity (format Unity expects)
  Serial.print("L:");
  Serial.print(lightValue);
  Serial.print(",B:");
  Serial.println(buttonPressed);


  //Short delay to avoid debouncing
  delay(20);
}
